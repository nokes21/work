# イラスト画像の置き場所メモ

あとで受け取るポケモンのイラスト（ご家族が用意した画像）をここに置きます。
今は `sample.svg`（「ここに イラスト」の仮の画像）が入っています。

- イーブイ

## ファイル名のルール（受け取ったら）

`pikachu.png`、`laplace.png` のように英字の名前にして、このフォルダに置きます。
背景が透明な PNG だときれいに馴染みます。
