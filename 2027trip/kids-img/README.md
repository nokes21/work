# イラスト画像の置き場所メモ

あとで受け取るポケモンのイラスト（ご家族が用意した画像）をここに置きます。
今は `sample.svg`（「ここに イラスト」の仮の画像）が入っています。

## ファイル名のルール（受け取ったら）

`pikachu.png`、`laplace.png` のように英字の名前にして、このフォルダに置きます。
背景が透明な PNG だときれいに馴染みます。

## メモ

- ゲーム（みやぎチャレンジ）の「だれが あそぶ？」は、キャラクターの画像ではなく、子どもたち一人ひとりのドット絵のままにする。
- プリキュア、パンどろぼうなどの画像も、送ってもらったらこども用しおりのイラストの枠に使う。
- 置き場所はおまかせ（画像を見てバランスよく配置する）。
- ラプラスはアップルタッチアイコン用の画像も届く予定 → 正方形（180×180px）に切り抜いて縮め、`2027trip/apple-touch-icon.png` を差し替える。
